# IP 运营工作台

给 **IP 运营操盘手**用的本地工作台，覆盖「找对标 → 拆爆款 → 选题 → 写稿 → 做计划 → 数据复盘」全流程，数据都存在本机、可追溯。

> 当前版本 v0.17.1。这是**给使用者看的说明**。

---

## 一、能做什么

- **首页**：视频号后台真实数据（粉丝、昨日新增、阅读、互动），每天 08:30 自动同步。
- **对标拆解 · 视频拆解**：粘贴链接或上传视频 → 自动解析下载 → 本地转写 → 标点整理 → 结构拆解。
- **对标拆解 · 账号拆解**：填对标账号昵称 → 查基础信息 → 按范围抓作品 → 双榜排序 → 账号分析 → 点「拆解这条」逐条深挖。
- **改写**：按对标视频的结构，生成我们自己的口播稿。
- **数据库 / 选题库 / 写稿 / 内容计划 / IP 档案**：逐步完善中。

---

## 二、安装

1. 下载本仓库的 ZIP 并解压到任意位置。
2. 双击 **`install.bat`**，自动装好 **git**、**Python 3.12** 和所有依赖（首次约下载 1.5GB，含显卡转写运行库）。
3. 双击 **`切换为自动更新.bat`**（**只做一次**），以后就能用 `更新.bat` 一键升级。
4. 双击 **`启动工作台.cmd`**，浏览器自动打开 `http://127.0.0.1:8741`。

> 详细手把手步骤见 [安装说明.md](安装说明.md)。

> 没有独立显卡也能用，转写会自动退回 CPU（慢一些）。

---

## 三、首次配置（三个 Key，各管一件事）

| 配置 | 在哪填 | 用途 |
|---|---|---|
| **DeepSeek API Key** | 设置 → 模型接入 | 云端拆解、账号分析、改写、标点整理 |
| **TikHub API Key** | 设置 → 数据接口 | 账号采集（对标账号的作品列表，按次付费） |
| **元宝登录** | 拆解页 →「元宝登录」按钮扫码 | 解析视频号链接 |

> 这些 Key 和登录态**只存在你自己的电脑上**，不回显、不外传、不进代码仓库。

## 四、常用操作

### 拆一条视频

1. 进入「对标拆解 → 视频拆解」。
2. 粘贴视频号链接（或上传视频文件）。
3. 等它自动：下载 → 转写 → 标点整理 → 拆解。
4. 在结果里看：结构分段、钩子、金句、转化、分镜。

### 拆一个账号

1. 进入「对标拆解 → 账号拆解」。
2. 填对标账号昵称（一字不差），点「查看基础信息」。
3. 看作品总数、更新频率，选采集范围（近 1/3/6/12 个月或全部）。
4. 点「开始抓取」，得到作品列表（双榜：历史爆款 + 近期 + 置顶）。
5. 点「生成账号分析」看定位、受众、选题、节奏。
6. 对想抄的作品点「拆解这条」。

### 改写

在拆解结果页点「去改写」，或左侧菜单「改写」，按结构生成我们自己的稿子。

### 看原始字幕

拆解页「原始字幕」标签，可切「时间轴 / 全文 / 标点整理」三种视图。

## 五、数据与隐私

- 所有数据都在本机 `data\` 目录，整体复制即可备份、迁移。
- 拆解时只发送**字幕文本**给云端模型，**不发视频文件**。
- 账号采集时只发送**昵称 / 账号 ID**给数据接口。
- 工作台只监听本机 `127.0.0.1`，不对外网开放。

## 六、更新到最新版

代码用 Git 管理。有新版本时，在项目文件夹执行：

```bash
git pull
```

你的数据在 `data\` 目录，更新**不会覆盖**你的 Key、登录态和历史数据。

## 七、常见问题

| 问题 | 解决 |
|---|---|
| 转写很慢 | 设置 → 转写模型改成 `small`（快、准度略降）；或确认显卡驱动已装 |
| 拆解失败「还没配置 Key」 | 到设置页填 DeepSeek API Key |
| 账号采集报 402 / 403 | TikHub Key 失效或余额不足，去设置页更新 Key |
| 链接解析失败 | 拆解页重新点「元宝登录」扫码 |
| 首页显示「登录过期」 | 首页点「重新扫码」 |
| 首次转写特别慢 | 正在下载语音模型（约 1.5GB），等一次就好 |

## 八、目录结构

```
app.py               启动入口
install.bat          一键装依赖
启动工作台.cmd        启动脚本
app\                 后端（接口、转写、拆解、账号分析、采集）
frontend\            前端（Vue 3，本地加载）
tools\               辅助脚本（media-parser 解析服务等）
data\                数据（数据库、模型、上传、登录态——不进 Git）
```
