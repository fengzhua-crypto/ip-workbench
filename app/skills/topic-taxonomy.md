# 选题分类方法

## 原则

1. 类目从账号自己的标题里归纳，不用外部预设的通用分类；
2. 8–12 个类目，覆盖绝大多数作品；
3. 类目之间不重叠；
4. 类目名 4–8 个字，用这个垂类的真实说法。

## 流程

1. 抽样（高信号 + 最新 + 均匀）标题；
2. 模型归纳类目名 + 一句话说明；
3. 逐条按类目表打标（只能选表里的类目）；
4. 代码统计每条类目的条数、占比、信号中位数。

## 模型规则

归纳类目时：给 8–12 个类目，类目之间不重叠，名字 4–8 个字，覆盖绝大多数作品，优先用账号自己在标题里用过的说法。每个类目附一句话说明它讲什么。
