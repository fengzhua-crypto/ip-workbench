# 钩子类型库

## 七种钩子

| 类型 | 定义 | 例子 | 心理机制 |
|---|---|---|---|
| 疑问 | 用问题开场 | "为什么孩子总爱哭？" | 求知欲 |
| 否定 | 挑战常识 | "别再把奶瓶放进微波炉" | 纠正心理 |
| 对比 | 制造反差 | "穷养和富养的孩子差在哪" | 冲突感 |
| 数字 | 用数字承诺 | "3 个信号判断缺钙" | 具体、可信 |
| 悬念 | 留半句 | "她只做了一个动作，结果…" | 完形冲动 |
| 身份共鸣 | 点中人群 | "当妈的都懂这个瞬间" | 认同感 |
| 直接结论 | 开门见山 | "奶粉冲错等于白喝" | 结论前置 |

## 模型规则

判断一条视频开头的钩子属于哪种类型，从 疑问 / 否定 / 对比 / 数字 / 悬念 / 身份共鸣 / 直接结论 中选一个，并说明它用了什么心理机制。钩子必须是开头 3 秒的原话，不要自己概括。
