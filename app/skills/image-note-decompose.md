# 图文笔记拆解

> 适用：小红书一类的图文笔记（多张图 + 标题 + 正文）。
> 与视频拆解的差别：没有时间轴、没有字幕、没有分镜；信息分布在标题、正文和图片里的文字。

---

## 拆解维度（固定八项）

| 维度 | 看什么 |
|---|---|
| 钩子 | 标题第一眼抓住人的那个点 |
| 公式 | 标题用了什么结构：年龄锚点 + 反常识结论 / 痛点 + 身份 …… |
| 关键词 | 这条笔记想被什么搜索词命中 |
| 标签 | 平台话题标签，系统自动从正文提取，不用你写 |
| 评论引导 | 正文或图上有没有留问题、留争议点让人想回 |
| 私信引导 | 有没有"私信领取""收藏码住"这类 |
| 整体号召 | 最后让人做什么 |
| 注意点 | 对标时容易踩的坑 |

## 图文结构：一张图一行

图片顺序**就是**结构，按位置判断角色：

| 位置 | 角色 | 通常干什么 |
|---|---|---|
| 第 1 张 | 封面 | 大字标题 / 对比图，决定点击 |
| 中间 | 内页1、内页2…… | 每张一个要点，配「一、二、三」编号 |
| 最后 1 张 | 结束 | 总结、引导评论、预告下一条 |

每张图只写**要点分析**：这一张在干什么、为什么放在这个位置。

---

## 模型规则

1. **一张图一条，不要合并**。index 必须与输入一一对应，漏一张就算不合格。
2. **要点分析不复述原文**。图上原文由系统单独展示，你只判断它「在干什么」。
3. **看不到画面就别说画面**。你只拿到图上文字，任何配色、构图、人物长相的描述都是编的。
4. **不编造数据**。点赞、收藏、播放一律不写。
5. **要点分析要具体到动作**：写「封面用一句不超过 12 字的反常识结论」，不要写「封面做得好」。
