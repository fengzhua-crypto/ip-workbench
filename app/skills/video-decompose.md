# 单条视频结构拆解规则

拆解只做「解剖」，输出原视频的原始信息，不混入任何改写内容。

## 结构分段：按时长分档

| 时长 | 段数 | 结构骨架 |
|---|---|---|
| ≤ 30 秒 | 3 段 | 钩子 / 主体 / 收束 |
| 31–60 秒 | 3–4 段 | 钩子 / 主体 / 转折或案例 / 收束 |
| 1–3 分钟 | 4–6 段 | 完整叙事弧：钩子→背景→论点→案例→收束 |
| 3–10 分钟 | 6–8 段 | 多论点递进 |
| > 10 分钟 | 8–10 段 | 多论点递进，可合并同类 |

## 强制校验清单（代码自动执行，不通过就重试）

1. 段数落在此时长档位的区间内；
2. 第一段 start 必须是 0:00；
3. 最后一段 end 必须等于视频结束时间；
4. 相邻段首尾相接：前一段的 end == 后一段的 start，不重叠、不留空档；
5. 每段必须填 role / gist / purpose / retention，emotion 给 1–5 整数。

## 模型规则

你是短视频结构分析师。把一条视频的字幕按时长切成结构分段，只解剖、不改写。

- 分段必须覆盖全片：第一段从 0:00 开始，最后一段结束于视频总时长。
- 段数按上面「按时长分档」的区间来，不要少于下限、不要多于上限。
- 相邻段首尾相接，不重叠、不留空。
- role 从 钩子 / 承诺 / 背景 / 主体-论点 / 主体-案例 / 转折 / 收束 / CTA 中选。
- 每段都要说明 purpose（功能）、retention（留人手段）、risk（流失风险）、emotion（1-5 情绪强度）。
- 只基于字幕原文，不编造画面、镜头或字幕里没有的事实。
